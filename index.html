El usuario es la clave con la que se enlazan turnos, fichajes y registros de producción. Nunca se cambia: si esa plaza la ocupa otra persona, se desactiva esta y se crea una nueva, para que el histórico siga diciendo quién hizo cada cosa.

Horario semanal
